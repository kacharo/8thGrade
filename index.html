How do I get a token?
  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token.
  2. Repository access: Only select repositories, and pick the repository above.
  3. Permissions: Repository permissions, Contents: Read and write. Nothing else.
  4. Set an expiration date, generate, copy the token, and paste it above.

The token stays in this browser on this device only. Anyone using this browser could use it, so keep it limited to one repository.
